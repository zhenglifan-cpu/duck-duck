# 多人合作游戏联机要求

> 实现多人合作联机架构指南。
> 不涉及 AI NPC 相关内容，仅覆盖纯玩家多人合作场景。
>
> 最后更新: 2026-05-11

---

## 一、核心需求

| 项目 | 说明 |
|------|------|
| 最大玩家数 | 可配置（示例: 4 人） |
| 匹配方式 | `free_match`（纯真人匹配，不使用 AI 填充） |
| 匹配超时 | 可配置（示例: 30 秒） |
| 超时行为 | 匹配到几人就几人开始（`immediately_start: true`） |
| 单机兼容 | 保留 Standalone 模式，`multiplayer.enabled: false` 时走单机 |

**多房间分配**：`max_players` 是每个房间的硬上限。排队人数超过上限时，匹配系统自动创建多个房间。此逻辑由引擎自动处理，无需额外代码。

## 二、匹配配置

### settings.json

```json
{
  "@runtime": {
    "multiplayer": {
      "enabled": true,
      "max_players": 4,
      "match_info": {
        "desc_name": "free_match",
        "match_timeout": 30,
        "player_number": 4,
        "immediately_start": true
      }
    }
  }
}
```

| 字段 | 含义 |
|------|------|
| `enabled` | `true` 启用联机 |
| `max_players` | 房间最大人数 |
| `desc_name` | `free_match` = 纯真人；`free_match_with_ai` = 超时后 AI 填充 |
| `match_timeout` | 匹配等待秒数 |
| `player_number` | 开局所需人数（`immediately_start: true` 时为上限而非硬性要求） |
| `immediately_start` | 超时后不等满人，有几个开几个 |

### 构建参数

```
entry_client: "main.lua"
entry_server: "main.lua"
```

客户端和服务端共用同一入口文件，由 `main.lua` 内部路由到不同模块。

## 三、架构设计：服务端权威（Server-Authoritative）

### 3.1 职责划分

```
┌─────────────────────────────────────────────┐
│              Server.lua                      │
│  - 创建场景（REPLICATED）                     │
│  - 构建地图（REPLICATED，客户端自动接收）       │
│  - 创建玩家节点 + 物理组件（REPLICATED）        │
│  - KCC 物理驱动（LOCAL，仅服务端运行）          │
│  - 读取客户端 controls → 驱动角色移动           │
│  - 游戏逻辑（阶段、碰撞、交互）                 │
│  - 广播远程事件                                │
└──────────────────┬──────────────────────────┘
                   │ 引擎自动同步:
                   │   节点位置/旋转/组件属性/节点变量
                   │ 远程事件:
                   │   阶段变化/交互/音效
                   ▼
┌─────────────────────────────────────────────┐
│              Client.lua                      │
│  - 接收同步场景（REPLICATED 节点自动到达）      │
│  - 创建本地模型/动画（LOCAL）                   │
│  - 本地相机 + 输入采集                         │
│  - 发送 controls 到服务端                      │
│  - HUD / UI 显示                              │
│  - 播放音效 / 特效（LOCAL）                    │
└─────────────────────────────────────────────┘
```

**关键原则**：

- **服务端是唯一权威**：所有游戏逻辑（移动、碰撞、状态判定）在服务端执行
- **客户端只做渲染和输入**：不做任何游戏逻辑判定，不运行物理
- **REPLICATED 节点自动同步**：服务端创建的 REPLICATED 节点，引擎自动复制到客户端
- **LOCAL 节点不同步**：相机、HUD、特效等使用 LOCAL 模式

### 3.2 模式路由（main.lua）

```lua
function Start()
    if IsServerMode() then
        Module = require("network.Server")
    elseif IsNetworkMode() then
        Module = require("network.Client")
    else
        Module = require("network.Standalone")
    end
    Module.Start()
end
```

三种模式：

| 模式 | 入口函数 | 触发条件 |
|------|---------|---------|
| 服务端 | `IsServerMode()` | 引擎分配为服务端实例 |
| 客户端 | `IsNetworkMode()` | 引擎分配为客户端实例 |
| 单机 | 其他 | `multiplayer.enabled = false` |

### 5.4 场景创建

```lua
function Shared.CreateScene(isServer)
    local scene = Scene()
    if isServer then
        -- 服务端: REPLICATED（复制给客户端）
        scene:CreateComponent("Octree")
        local pw = scene:CreateComponent("PhysicsWorld")
        pw:SetGravity(Vector3(0, -9.81, 0))
    else
        -- 客户端: LOCAL（不影响网络同步）
        scene:CreateComponent("Octree", LOCAL)
        local pw = scene:CreateComponent("PhysicsWorld", LOCAL)
        pw:SetGravity(Vector3(0, -9.81, 0))
        scene:CreateComponent("DebugRenderer", LOCAL)
    end
    return scene
end
```

## 六、Server.lua — 服务端逻辑

### 6.1 启动流程

```

  ├── Shared.CreateScene(true)       -- 创建 REPLICATED 场景
  ├── 构建地图（REPLICATED）           -- 客户端自动接收
  ├── CreateRolePool()               -- 预创建角色节点池
  ├── 订阅 CLIENT_READY 事件
  ├── 订阅 ClientDisconnected 事件
  └── 订阅 Update 事件
```

### 6.2 角色节点池（预创建模式）

服务端启动时预创建 `MAX_PLAYERS` 个角色节点，玩家连接时分配空闲槽位：

```lua
function CreateRolePool()
    for roleId = 1, MAX_PLAYERS do
        local roleNode = CreatePlayerRole(roleId, spawnPos)
        rolePool_[roleId] = roleNode
        roleAssignments_[roleId] = nil  -- 初始无人占用
    end
end
```

### 6.3 玩家角色节点创建

每个角色节点包含以下组件：

```lua
function CreatePlayerRole(roleId, spawnPos)
    local roleNode = scene_:CreateChild("Role_" .. roleId, REPLICATED)
    roleNode.position = spawnPos

    -- RigidBody (REPLICATED) — 冻结线性/角速度，由 KCC 驱动
    local body = roleNode:CreateComponent("RigidBody", REPLICATED)
    body:SetCollisionLayerAndMask(CollisionLayerCharacter, CollisionMaskCharacter)
    body.mass = 1.0
    body:SetLinearFactor(Vector3.ZERO)
    body:SetAngularFactor(Vector3.ZERO)
    body:SetCollisionEventMode(COLLISION_ALWAYS)

    -- CollisionShape (REPLICATED)
    local shape = roleNode:CreateComponent("CollisionShape", REPLICATED)
    shape:SetCapsule(PLAYER_RADIUS * 2, PLAYER_HEIGHT,
                     Vector3(0, PLAYER_HEIGHT / 2, 0))

    -- KCC (LOCAL) — 仅服务端运行物理驱动
    local kcc = roleNode:CreateComponent("KinematicCharacterController", LOCAL)
    kcc:SetCollisionLayerAndMask(CollisionLayerKinematic, CollisionMaskKinematic)
    kcc:SetJumpSpeed(8.0)

    -- CharacterComponent (REPLICATED) — 移动状态自动同步到客户端
    local character = roleNode:CreateComponent("CharacterComponent", REPLICATED)
    character:SetWalkSpeed(MOVE_SPEED)
    character:SetRunSpeed(MOVE_SPEED)
    character:SetEnableWalkMode(true)
    character:SetAirControlFactor(0.6)
    character.autoRotateToMoveDir = false
    character.rotationSpeed = 1440.0

    -- 节点变量（自动同步到客户端）
    roleNode:SetVar("IS_ROLE", Variant(true))
    roleNode:SetVar("SLOT_INDEX", Variant(roleId))

    return roleNode
end
```

**REPLICATED vs LOCAL 规则**：

| 组件 | 模式 | 原因 |
|------|------|------|
| RigidBody | REPLICATED | 碰撞检测需要双端感知 |
| CollisionShape | REPLICATED | 同上 |
| KinematicCharacterController | **LOCAL** | 只在服务端运行物理，客户端不需要 |
| CharacterComponent | REPLICATED | 移动速度/状态等属性需同步到客户端驱动动画 |

### 6.4 玩家连接/断线流程

```
ClientReady 事件:
  1. connection.scene = scene_           -- 关联场景，开始同步
  2. FindFreeRole()                      -- 找空闲槽位
  3. roleNode:SetOwner(connection)       -- 设置节点所有者
  4. roleNode:SetVar("CONNECTED", true)  -- 标记已连接
  5. 延迟一帧发送 ASSIGN_ROLE 事件        -- 确保场景同步完成

ClientDisconnected 事件:
  1. roleNode:SetOwner(nil)              -- 清除所有者
  2. roleNode:SetVar("CONNECTED", false) -- 标记已断线
  3. ResetRoleState(roleId)              -- 重置位置到出生点
  4. 清理连接映射表
```

**延迟一帧的必要性**：`connection.scene = scene_` 后引擎需要时间同步场景数据到客户端，立即发送 `ASSIGN_ROLE` 时客户端可能还找不到对应节点。

### 6.5 角色移动（服务端驱动）

```lua
function MoveRole(roleNode, connection, dt)
    local character = roleNode:GetComponent("CharacterComponent")
    local controls = connection.controls
    local buttons = controls.buttons

    -- 客户端位掩码 → CharacterComponent 引擎控制标志
    character.controls:Set(CTRL_FORWARD, (buttons & CTRL.FORWARD) ~= 0)
    character.controls:Set(CTRL_BACK,    (buttons & CTRL.BACK) ~= 0)
    character.controls:Set(CTRL_LEFT,    (buttons & CTRL.LEFT) ~= 0)
    character.controls:Set(CTRL_RIGHT,   (buttons & CTRL.RIGHT) ~= 0)
    character.controls:Set(CTRL_JUMP,    (buttons & CTRL.JUMP) ~= 0)
    character.controls:Set(CTRL_RUN,     (buttons & CTRL.RUN) ~= 0)

    character.controls.yaw   = controls.yaw
    character.controls.pitch = controls.pitch
end
```

**完整数据流**：

```
客户端键盘 → buttons 位掩码 → serverConn.controls.buttons
                                      ↓ (引擎自动传输)
              服务端 connection.controls.buttons → character.controls
                                                        ↓
                                              KCC 物理驱动移动
                                                        ↓
                                              节点位置更新 (REPLICATED)
                                                        ↓ (引擎自动同步)
                                              客户端节点位置更新 → 渲染
```

### 6.6 Update 循环

```lua
function HandleUpdate(eventType, eventData)
    local dt = eventData:GetFloat("TimeStep")

    -- 驱动所有已连接的玩家角色
    for roleId, connKey in pairs(roleAssignments_) do
        if connKey then
            local roleNode = rolePool_[roleId]
            local connection = serverConnections_[connKey]
            if connection and roleNode then
                MoveRole(roleNode, connection, dt)
            end
        end
    end

    -- 游戏逻辑（阶段更新、碰撞检测等）
    -- ...
end
```

### 7.3 角色绑定

收到 `ASSIGN_ROLE` 后绑定自己控制的角色节点：

```lua
function HandleAssignRole(eventType, eventData)
    local nodeId = eventData["NodeId"]:GetUInt()
    local roleNode = scene_:GetNode(nodeId)
    if roleNode then
        TryBindToRole(roleNode)
    else
        pendingNodeId_ = nodeId  -- 节点尚未复制到客户端，等待
    end
end

function TryBindToRole(roleNode)
    local character = roleNode:GetComponent("CharacterComponent")
    if character == nil then return false end  -- 组件尚未复制

    myRoleNode_ = roleNode
    yaw_ = roleNode.rotation:YawAngle()

    -- 相机跟随
    tpCamera_:Update(1.0, myRoleNode_, yaw_, pitch_)

    -- 绑定 GameHUD（移动端触控摇杆直接写入 controls）
    local serverConn = network:GetServerConnection()
    if serverConn then
        GameHUD.SetControls(serverConn.controls)
    end
    return true
end
```

`pendingNodeId_` 在 `HandleUpdate` 中每帧重试，直到节点和 `CharacterComponent` 都到达。

### 7.4 其他玩家模型创建（LOCAL）

通过 `NodeAdded` 事件检测服务端复制过来的角色节点，为其创建 LOCAL 模型和动画：

```lua
function HandleNodeAdded(eventType, eventData)
    local node = eventData["Node"]:GetPtr("Node")
    if node and node.replicated then
        table.insert(pendingRoleNodes_, node.ID)
    end
end
```

在 `HandleUpdate` 中处理队列，**只为 `CONNECTED=true` 的节点创建模型**：

```lua
if #pendingRoleNodes_ > 0 then
    local nodesToCheck = pendingRoleNodes_
    pendingRoleNodes_ = {}
    for _, nodeId in ipairs(nodesToCheck) do
        local node = scene_:GetNode(nodeId)
        if node then
            local isRoleVar = node:GetVar("IS_ROLE")
            if not isRoleVar:IsEmpty() and isRoleVar:GetBool() then
                local connectedVar = node:GetVar("CONNECTED")
                local isConnected = (connectedVar ~= nil
                    and not connectedVar:IsEmpty()
                    and connectedVar:GetBool())
                if isConnected then
                    SetupCharacterVisuals(node)
                else
                    -- CONNECTED 尚未同步，放回队列下帧重试
                    table.insert(pendingRoleNodes_, nodeId)
                end
            end
        end
    end
end
```

模型创建使用 prefab + AnimationStateMachine：

```lua
function SetupCharacterVisuals(roleNode)
    local nodeId = roleNode.ID
    if playerAnimData_[nodeId] then return end

    -- 加载 prefab
    local modelNode = scene_:InstantiateXML(PLAYER_PREFAB, Vector3.ZERO, Quaternion.IDENTITY, LOCAL)
    modelNode.name = "ModelNode"
    modelNode.parent = roleNode

    -- 加载动画状态机
    modelNode:GetOrCreateComponent("AnimationController", LOCAL)
    local asm = modelNode:CreateComponent("AnimationStateMachine", LOCAL)
    local fsmFile = cache:GetResource("JSONFile", PLAYER_FSM)
    if fsmFile then
        asm:LoadFromJSONFile(fsmFile)
        asm:Start()
    end

    playerAnimData_[nodeId] = { fsm = asm, modelNode = modelNode }
end
```

### 7.5 输入发送

**PC 键盘输入**（移动端由 GameHUD 自动处理）：

```lua
function UpdateInput(dt)
    if myRoleNode_ == nil then return end

    -- 鼠标视角
    if not touchEnabled then
        yaw_   = yaw_ + input.mouseMoveX * MOUSE_SENSITIVITY
        pitch_ = pitch_ + input.mouseMoveY * MOUSE_SENSITIVITY
    end
    pitch_ = Clamp(pitch_, -80.0, 80.0)

    local serverConn = network:GetServerConnection()
    if serverConn then
        serverConn.controls.yaw   = yaw_
        serverConn.controls.pitch = pitch_

        -- PC 键盘 → buttons 位掩码
        if not touchEnabled then
            local buttons = 0
            if input:GetKeyDown(KEY_W) then buttons = buttons | CTRL.FORWARD end
            if input:GetKeyDown(KEY_S) then buttons = buttons | CTRL.BACK    end
            if input:GetKeyDown(KEY_A) then buttons = buttons | CTRL.LEFT    end
            if input:GetKeyDown(KEY_D) then buttons = buttons | CTRL.RIGHT   end
            if input:GetKeyDown(KEY_SPACE) then buttons = buttons | CTRL.JUMP end
            if input:GetKeyDown(KEY_SHIFT) then buttons = buttons | CTRL.RUN end
            serverConn.controls.buttons = buttons
        end
    end
end
```

function DriveAnimations(dt)

    end

### 7.7 断线清理

在 `HandleUpdate` 中检测其他玩家断线，移除其 LOCAL 模型：

```lua
for nodeId, data in pairs(playerAnimData_) do
    local node = scene_:GetNode(nodeId)
    if not node then
        -- 节点已被服务端删除
        playerAnimData_[nodeId] = nil
    elseif node ~= myRoleNode_ then
        local connectedVar = node:GetVar("CONNECTED")
        -- 仅当 CONNECTED 明确为 false 时移除（断线清理）
        -- 空/未同步时不操作，避免误删
        if not connectedVar:IsEmpty() and not connectedVar:GetBool() then
            RemoveCharacterVisuals(node)
        end
    end
end
```

## 八、CONNECTED 变量的三态处理

网络变量同步有延迟，`CONNECTED` 存在三种状态，必须分别处理：

| 状态 | 含义 | 创建模型 | 清理模型 |
|------|------|---------|---------|
| **空**（未同步到客户端） | 变量还没从服务端到达 | 放回队列重试 | **不操作** |
| **true** | 玩家已连接 | 创建 | 保留 |
| **false** | 玩家已断线 | 不创建 | 移除 |

**关键原则**：`NodeAdded` 只保证节点到达，不保证所有 Var 已同步。对 `CONNECTED` 的检查必须支持重试，不能一次性判定。将"空"等同于"false"会导致模型创建被永久跳过。

## 十、断线处理

| 场景 | 处理 |
|------|------|

## 十一、常见陷阱与解决方案

### 陷阱 1: 客户端自建地图导致穿模

**错误**：客户端调用 `MapBuilder.Build(scene_, { createMode = LOCAL })`，同时服务端也有 REPLICATED 地图 → 两份重叠地图，物理碰撞混乱。

**正确**：客户端不构建地图，完全依赖服务端的 REPLICATED 节点。

### 陷阱 2: 客户端只发送 yaw/pitch，不发送 buttons

**错误**：`UpdateInput()` 只写 `serverConn.controls.yaw/pitch`，遗漏 `serverConn.controls.buttons` → 角色无法移动。

**正确**：PC 键盘输入必须编码为 buttons 位掩码并写入 `serverConn.controls.buttons`。移动端由 `GameHUD.SetControls()` 自动处理。

### 陷阱 3: 服务端不创建模型/动画，客户端用白膜替代

**两种可行架构，选其一**：

| 架构 | 服务端 | 客户端 | 优缺点 |
|------|--------|--------|--------|
| **A: 服务端创建 REPLICATED 模型** | 创建 ModelNode + prefab + FSM (REPLICATED) | 自动接收，无需额外代码 | 简单但网络流量略大 |
| **B: 客户端创建 LOCAL 模型** | 只创建物理组件 | 通过 NodeAdded 检测角色节点，LOCAL 创建 prefab + FSM | 灵活但需处理同步竞态 |

**选择架构 B 时必须注意**：需要正确处理 `CONNECTED` 三态（见第八节），否则会出现"看不到对方"或"幽灵玩家"问题。

### 陷阱 4: 远程事件发送时机过早

**错误**：`connection.scene = scene_` 后立即发送 `ASSIGN_ROLE` → 客户端找不到对应节点。

**正确**：延迟一帧后再发送。

```lua
DelayOneFrame(function()
    conn:SendRemoteEvent(EVENTS.ASSIGN_ROLE, true, assignData)
end)
```

### 陷阱 5: 角色池中空位显示模型

**错误**：预创建 4 个角色节点，但只有 2 人匹配进来。客户端为所有 `IS_ROLE=true` 的节点创建模型 → 出现 2 个不动的"幽灵玩家"。

**正确**：只为 `CONNECTED=true` 的节点创建模型。空位的 `CONNECTED` 始终为 `nil`（从未被设置过），不会触发创建。
