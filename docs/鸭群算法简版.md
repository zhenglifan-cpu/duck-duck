基于Boids集群行为的鸭群AI和玩家驱赶系统（简版）

# 一、算法目标

基于Boids 集群行为和现实赶鸭中鸭的flocking /following instinct/flight response，实现一套有涌现行为、可调参、适合 Lua 的鸭群系统。

这套系统要实现5个结果：

1.自然成群:鸭默认倾向于跟随同伴、维持群体，不会长期单独游荡。现实资料也指出鸭最典型的行为特征就是强烈的 flocking 与 following instinct。

2.受惊逃逸:鸭看到玩家、威胁源或被快速逼近时，会朝远离威胁的方向移动；这对应现实赶鸭中的 flight response。

3.局部带动整体:一只鸭先跑，邻近鸭会通过对齐与聚合加入流动，形成"头鸭跑、其他鸭跟"的传播效应。

4.慢压可移、猛冲可散:玩家缓慢逼近时，鸭群整体位移；快速冲入或喊叫过强时，鸭群会短时分裂、散开、惊慌。

5.低规则，高涌现:系统尽量不用复杂状态脚本，而用四条核心规则叠加出群体行为。

# 二、鸭群集群AI

## （一）规则说明

Boids 四规则：分离 + 对齐 + 聚合 + 逃逸 - 鸭有"视野半径"，只受附近邻居影响- 不同性格的鸭（胆小/倔强/领头鸭）增加策略深度 - 群体越大越难分散，落单的鸭更容易控制

鸭不是单独个体，而是一个有涌现行为的集群系统，基于经典 [Boids 算法](https://www.red3d.com/cwr/boids/"%20\t%20"https://maker.taptap.cn/app/_blank)的三条规则：

| 规则  | 行为  | 游戏表现 |
| --- | --- | --- |
| 分离（Separation） | 避免拥挤 | 鸭之间保持间距，不会叠在一起 |
| 对齐（Alignment） | 跟随邻居方向 | 一只鸭跑动会带动附近的鸭跟着跑 |
| 聚合（Cohesion） | 靠近群体中心 | 散开的鸭会自动向群体靠拢 |
| 逃逸（Escape） | 逃离玩家 | 检测到玩家/威胁时，朝远离方向逃跑 |

这四条规则的叠加产生了非常自然的鸭群行为：冲过去它们会散，慢慢靠近它们会移，头鸭跑了其他鸭跟着跑。

### 1.分离Separation

**目的：**避免个体重叠，保持自然间距。

**输入：**感知半径内其他鸭的位置。

**行为：**对过近邻居产生反向排斥力。

**表现：**

- 鸭群不会堆成一个点
- 狭窄处会出现挤压感
- 冲刺进入鸭群时，个体会向外散

**核心逻辑：**

- 距离越近，排斥越强
- 只在"过近阈值"内显著生效

**公式概念：**

Separation = Σ normalize(self.pos - neighbor.pos) / distance

### 2.对齐 Alignment

**目的：**让个体跟随邻居方向，形成群体流动。

**输入：**邻居鸭的速度向量。

**行为：**向邻居平均速度方向修正自己的速度。

**表现：**

- 一只鸭开始跑，周围鸭会逐步跟着跑
- 狭道中会形成整体"流"
- 局部方向会传播

**核心逻辑：**

- 附近鸭越多，对齐越明显
- 没有邻居时，对齐不生效

**公式概念：**

Alignment = average(neighbor.velocity) - self.velocity

### 3.聚合 Cohesion

**目的：**让鸭回到群体中，减少长期脱队。

**输入：**邻居鸭的位置中心。

**行为：**朝邻居平均位置靠近。

**表现：**

- 散开的鸭会慢慢回群
- 鸭群被玩家冲散后，会重新聚拢
- 小群会合并成更稳定的大群

**核心逻辑：**

- 距离群体中心越远，聚合越明显
- 在高惊慌时适当降低权重，避免"立刻贴回去"显得僵硬

**公式概念：**

Cohesion = average(neighbor.position) - self.position

### 4.逃逸 Escape

**目的：**模拟鸭对玩家、天敌、噪声等威胁的逃离反应。

**输入：**

- 玩家位置
- 玩家的速度方向
- 喊叫事件
- 其他威胁源

**行为：**

- 朝远离威胁的方向移动
- 威胁越近、越快、越正面，逃逸越强

**表现：**

- 玩家慢慢靠近，鸭群整体前移
- 玩家突然冲进来，鸭群局部炸散
- 喊叫会造成瞬时转向或加速

现实资料指出，人类和天敌会被鸭视为显著威胁；若驱赶压力过大，会出现 running、bunching、jumping、squeezing through barriers 等逃逸和挤压行为。这个游戏系统可以用 Escape 权重和 Separation/Cohesion 的再分配来近似。

**公式概念：**

Escape = Σ normalize(self.pos - threat.pos) \* threatInfluence

## （二）鸭的状态模型

### 1.Idle 怠速

**触发**

- 附近没有鸭
- 附近没有玩家
- 没有明显目标

**表现**

- 慢速游走或停顿
- 朝随机微方向摆动

### 2.Flock 跟群

**触发**

- 感知到一定数量邻居
- 没有玩家威胁

**表现**

- Alignment + Cohesion 主导
- 形成稳定鸭群流动

### 3.Alert 警觉

**触发**

- 玩家进入外圈威胁半径
- 或听到较弱喊叫

**表现**

- 群体方向开始偏转
- 速度轻微增加

### 4.Panic 惊慌

**触发**

- 玩家快速冲近
- 喊叫命中
- 多个威胁叠加
- 陷入狭窄且受压

**表现**

- Escape 显著提高
- Separation 提高
- Cohesion 降低
- 速度上升，但方向波动更大

### 5.Recover 恢复

**触发**

- 威胁离开
- 一段时间未再受压

**表现**

- Panic 缓慢衰减
- 鸭从炸散回到 flock 状态

## （三）感知系统

每只鸭每次更新需要感知：

- 附近鸭
- 附近玩家
- 喊叫事件
- 墙体 / 障碍
- 目标点或安全区（可选）
