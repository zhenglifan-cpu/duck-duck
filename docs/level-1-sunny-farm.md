# 关卡一：阳光牧场 — 详细设计文档

> 隶属项目：《赶鸭子上架》
> 关联文档：[game-design.md](game-design.md)
> 状态：**已完成（可游玩）**

---

> 作为第一个关卡，阳光牧场承担**教学 + 建立核心乐趣**的双重任务。
> 玩家在一个阳光明媚的牧场中，将 8 只鸭子赶入右侧的 U 形围栏目标区。

| 项目 | 数值 |

| ★★☆ 目标 | 赶入 7 只 |
| ★★★ 目标 | 赶入全部 8 只 |
| 玩家出生点 | 底部中央区域 |
| 目标区域 | 右侧 U 形围栏，开口朝左 |

## 四、鸭子初始位置与行为

### 4.1 初始分布

8 只鸭子散布在场地中央，模拟自然散落状态：

| 编号 | 初始位置 (X, Z) | 区域描述 |
|------|-----------------|---------|

| d5 | (11, 5) | 靠近目标区 |

| d7 | (8, 10) | 中上方 |
| d8 | (12, 3) | 右下方 |

### 4.2 AI 参数（第一关，偏简单）

```lua
-- 基础行为
MoveSpeed        = 2.0    -- 鸭子基础移动速度 (m/s)，比玩家慢
FearRadius       = 3.5    -- 玩家靠近此距离开始逃跑 (m)
ClapFearRadius   = 5.0    -- 拍手惊吓范围 (m)
ClapFearBoost    = 1.8    -- 拍手额外恐惧力系数
CohesionRadius   = 4.0    -- 聚合感知范围 (m)
SeparationDist   = 0.8    -- 最小间距 (m)
WanderStrength   = 0.3    -- 闲逛随机力（低 = 不太乱跑）
CalmDownTime     = 2.0    -- 受惊→平静恢复时间 (s)
SettleTime       = 1.5    -- 进入目标区后停留多久算"上架" (s)
MaxSpeed         = 3.5    -- 最大速度限制 (m/s)

-- Boids 权重
SeparationWeight = 1.5
CohesionWeight   = 0.8
AlignmentWeight  = 0.3
FearWeight       = 3.0
WanderWeight     = 0.5
BoundaryWeight   = 2.0
ObstacleWeight   = 2.5
```

### 4.3 上架后行为

鸭子进入目标区并成功"上架"（停留 1.5 秒）后，进入安定状态：

| 行为 | 参数 | 说明 |
|------|------|------|
| **围栏内闲逛** | 速度 0.6 m/s | 在围栏范围内缓慢踱步 |
| **随机跳跃** | 间隔 3~7 秒，高度 0.25m | 活泼感，跳跃时长 0.4s |
| **身体变色** | 微绿色 (0.8, 0.9, 0.8) | 视觉区分已上架 |
| **头顶标记** | 显示 ✓ | 确认已上架 |
| **逃跑机制** | 见下方 | 所有玩家远离时有概率逃出 |

### 4.4 鸭子逃跑机制

当**所有玩家**与目标区域的距离都超过 `EscapeDistance`（10m）时，已上架的鸭子有概率逃出围栏：

```
判定间隔: 每 15 秒一次 (EscapeCheckInterval)
逃跑概率: 1/15 ≈ 6.7% (EscapeChance)
触发条件: 所有玩家距离 > 10m
逃跑效果: 鸭子回到 idle 状态，从围栏开口跑出
网络事件: DUCK_ESCAPED
```

> 设计意图：鼓励玩家分工——不能全员去追远处的鸭子，需要有人留守围栏附近。

## 五、目标区域机制

```
目标区域 = U形围栏围成的半封闭空间
- 位置: 中心 (15, 0, 6)，面积 4m × 5m
- 三面围栏（上、右、下），左侧开口宽 3m
- 地面用浅黄色材质 (0.85, 0.78, 0.5) 区分
- 围栏内放置干草和饮水池作为装饰
- 检测: 鸭子进入后停留 1.5 秒 → 计为"上架"
- 上架后: 鸭子切换为安定状态（闲逛 + 跳跃，详见 4.3）
- 已上架的鸭子不会被玩家惊走（安全区设计）
- 但所有玩家远离时有概率逃跑（详见 4.4）
```

## 六、相机参数

```lua
Camera = {
    TargetPos = Vector3(9, 0, 5.5),  -- 看向地图中心（略偏南，露出前方道路）
    Distance  = 17,                   -- 距中心距离 (m)
    Yaw       = 0,                    -- 水平旋转角 (度, 0 = 围栏与屏幕平行)
    Pitch     = -55,                  -- 垂直俯角 (度, -55 = 较陡俯视)
    Fov       = 42,                   -- 视野角度
    NearClip  = 0.5,
    FarClip   = 200.0,
}
```

> 相机设计：Yaw=0 使围墙与屏幕边缘平行，Pitch=-55 提供接近俯视的视角，Distance=17 确保 18×12m 的农场填满画面。TargetPos 略偏南方，使外围道路和前方环境也可见。

## 十、教学流程设计

第一关通过**地图布局本身**引导玩家，不设强制教程弹窗：

| 阶段 | 玩家行为 | 设计意图 |
|------|---------|---------|
| **开局** | 出生在底部中央，前方有散布的鸭子 | 自然发现"靠近鸭子 → 鸭子跑开" |
| **发现拍手** | 屏幕底部提示"按空格拍手" | 学会拍手驱赶 |
| **理解方向** | 鸭子被赶向远离玩家的方向 | 理解"站位 → 驱赶方向"的核心策略 |
| **成群驱赶** | 中央几只鸭子距离较近，可一起赶 | 体验 Boids 集群行为的乐趣 |
| **挑战满星** | 左上和右上的鸭子较分散 | 满星需要策略性走位，有成就感 |
| **逃跑惊喜** | 全跑去抓远处鸭子时，围栏里的鸭子可能逃跑 | 学会分工和看守策略 |

## 十一、完成流程与金币结算

```
赶入第 5 只鸭子 → HUD 显示 ★☆☆
赶入第 7 只鸭子 → HUD 更新 ★★☆
赶入全部 8 只   → HUD 更新 ★★★ + 庆祝音效

任意时刻可按 ESC → 弹出结算面板 → 显示结算结果
```

### 结算面板

```
┌──────────────────────────────────────┐
│          🌾 关卡完成！               │
│                                      │
│     上架鸭子: 7/8                     │
│     评价: ★★☆                       │
│                                      │
│     ── 金币结算 ──                   │
│     上架奖励: 7 × 1 = 7 枚           │
│     星级奖励:         2 枚           │
│     ─────────────────                │
│     本局获得:         9 枚 💰         │
│                                      │
│          [ 返回主菜单 ]              │
└──────────────────────────────────────┘
```

**金币计算公式**: `earnedGold = settledCount + starRating`

| 上架数 | 星级 | 金币 |
|--------|------|------|
| 5 只 | ★☆☆ (1星) | 5 + 1 = 6 枚 |
| 7 只 | ★★☆ (2星) | 7 + 2 = 9 枚 |
| 8 只 | ★★★ (3星) | 8 + 3 = 11 枚 |

金币通过 `clientCloud` 云端存储，跨设备持久化。

## 十二、网络事件

本关卡涉及的远程事件（多人模式）：

| 事件 | Key | 用途 |
|------|-----|------|
| 客户端就绪 | `E_ClientReady` | 客户端加载完成通知 |
| 角色分配 | `E_AssignRole` | 服务端分配 P1~P4 |
| 玩家拍手 | `E_PlayerClap` | 客户端→服务端，驱赶鸭子 |
| 鸭子上架 | `E_DuckSettled` | 服务端→客户端，通知上架 |
| 鸭子逃跑 | `E_DuckEscaped` | 服务端→客户端，通知逃出 |
| 游戏结算 | `E_GameResult` | 服务端→客户端，附带 EarnedGold |
