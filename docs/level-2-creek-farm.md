## 二、场景特点：被溪流一分为二的农庄

### 2.1 核心场景概念

一条蜿蜒的溪流将地图**从左上到右下斜切为两半**，形成天然的地形分隔：

- **左岸（西岸）**：开阔草地 + 菜园 + 小木桥出发点，大部分鸭子散布于此
- **右岸（东岸）**：谷仓 + 目标围栏 + 干草堆、道具区
- **溪流**：宽约 2.5~3m 的浅水带，贯穿地图，是玩法的核心地理要素
- **石桥**：地图中部偏下的一座石桥，是陆地上唯一的跨河通道

> 设计思路：第一关是全草地平面，玩家只需"赶就完事"。
> 第二关通过溪流制造**地形断裂**——鸭子可以自由穿越水面，但玩家过河必须绕路走桥。
> 这迫使玩家思考走位策略，而不只是追着鸭子跑。

### 2.3 溪流形态

溪流并非直线，而是一条自然弯曲的 S 形水带：

```
溪流走向（从左上到右下）：

  起点: (8, 14)   — 从地图顶部进入
    ↓ 微微右弯
  拐点: (10, 10)  — 向右弯曲
    ↓ 经过地图中央
  中段: (8, 6.5)  — 回弯到中央偏左
    ↓ 继续向下
  石桥: (8, 3.5)  — 桥下穿过
    ↓ 向右下延伸
  终点: (6, 0)    — 从地图底部流出
```

| 属性 | 数值 |
|------|------|
| 宽度 | 2.5~3.0m（窄处 2.5m，宽处 3.0m） |
| 深度 | 视觉上约 0.15m（浅水，可看到河床） |
| 水面高度 | Y = -0.05（略低于草地，形成凹陷感） |
| 水面颜色 | 半透明蓝绿 (0.3, 0.6, 0.75, 0.7) |
| 河床颜色 | 浅沙色 (0.7, 0.65, 0.5) |
| 流动效果 | UV 动画模拟水面流动方向（左上→右下） |

## 三、玩法与场景的交互方式

### 3.1 水域对鸭子的影响

水域是本关的核心玩法要素。鸭子作为水禽，对水有天然的亲和力：

| 鸭子类型 | 在陆地上 | 在水中 | 上岸倾向 |
|---------|---------|-------|---------|
| **普通鸭** | 正常行为（同第一关） | 移速降为 60%，恐惧半径缩小到 2.0m | 随机方向上岸 |
| **水鸭** 🆕 | 正常行为，但每 8~12s 判定一次想回水 | 移速 **提升** 120%，恐惧半径仅 1.5m | 极不愿上岸，被赶上岸后 8~12s 想回水 |

**核心矛盾**：鸭子进水后变得极难驱赶——它们在水里"如鱼得水"，玩家的拍手驱赶效果大幅减弱。而水鸭更是主动往水里跑，成为满星的关键挑战。

### 3.2 水域对玩家的影响

| 区域 | 玩家行为 |
|------|---------|
| **陆地** | 正常移速 4.0 m/s，冲刺 6.5 m/s |
| **溪流中** | 移速降为 **50%**（2.0 m/s），**无法冲刺**，拍手范围缩小到 3.0m |
| **石桥上** | 正常移速，等同陆地 |

> 设计意图：玩家**可以**下水追鸭子，但代价很高。
> 更聪明的策略是利用多人配合，在岸上截住鸭子的上岸方向。

### 3.3 石桥 — 战略要地

地图中部偏下的一座石桥是唯一的"免费"过河通道：

| 属性 | 数值 |
|------|------|
| 位置 | 中心约 (8, 3.5) |
| 宽度 | 2.5m（可双人并行） |
| 长度 | 3.5m（横跨溪流） |
| 材质 | 石板桥面 + 低矮石栏 |

**策略作用**：
- 桥是连接两岸的咽喉，控制桥面 = 控制鸭子的陆上路线
- 玩家可以在桥头拍手，阻止鸭子从桥面逃到对岸
- 多人合作时，一人守桥、其余人驱赶是高效策略

### 3.4 面包屑道具 — 引诱水鸭上岸 🆕

本关首次引入**面包屑**道具，作为应对水鸭的战术工具：

| 属性 | 数值 |
|------|------|
| 拾取位置 | 谷仓旁木箱上 (16, 3) |
| 使用方式 | 按 E 键撒在地面（陆地或桥面） |
| 吸引范围 | 6m 半径 |
| 持续时间 | 8 秒 |
| 吸引力权重 | 4.0（高于恐惧力的 3.0） |
| 刷新 | 使用后 15 秒在原位刷新 |
| 数量限制 | 地图上同时只存在 1 个面包屑拾取点 |

**核心玩法**：
1. 水鸭在水里几乎赶不动（恐惧半径仅 1.5m，水中移速 120%）
2. 面包屑的吸引力 > 恐惧力，可以"引诱"水鸭主动上岸
3. 面包屑撒在目标区附近 → 水鸭走过来 → 趁机赶入围栏
4. 但面包屑有 CD，需要合理规划使用时机

### 4.2 水鸭专属 AI 参数 🆕

```lua
WaterDuck = {
    -- 继承普通鸭基础参数，以下为覆盖项
    WaterAffinity      = 0.8,     -- 水域亲和力（0~1，越高越想待在水里）
    ReturnToWaterInterval = {8, 12}, -- 上岸后多久想回水的判定间隔 (s)
    ReturnToWaterChance = 0.6,    -- 每次判定回水的概率 (60%)

    -- 在水中的参数修改
    InWater_MoveSpeed   = 2.4,    -- 水中移速 120%（基础 2.0 × 1.2）
    InWater_FearRadius  = 1.5,    -- 水中恐惧半径大幅缩小
    InWater_MaxSpeed    = 3.0,    -- 水中最大速度

    -- 在陆地上的参数（与普通鸭一致）
    OnLand_MoveSpeed    = 2.0,
    OnLand_FearRadius   = 3.5,

    -- 外观区分
    BodyColor = Color(0.75, 0.85, 0.95, 1.0),  -- 浅蓝灰色身体
    HeadColor = Color(0.2,  0.55, 0.35, 1.0),  -- 深绿色头部（绿头鸭）
    BeakColor = Color(0.9,  0.75, 0.2,  1.0),  -- 黄嘴
}
```

### 4.3 普通鸭在水中的参数调整

```lua
NormalDuck_InWater = {
    MoveSpeed   = 1.2,   -- 水中移速 60%（基础 2.0 × 0.6）
    FearRadius  = 2.0,   -- 恐惧半径缩小（陆地 3.5 → 水中 2.0）
    MaxSpeed    = 2.5,   -- 最大速度降低
    -- 其余参数不变
}
```

## 九、玩法创新点总结

### 9.1 与第一关的关键差异

| 维度 | 第一关：阳光牧场 | 第二关：溪流农庄 |
|------|-----------------|-----------------|
| **地形** | 全平面草地 | 溪流分割两岸 + 石桥 |
| **鸭子种类** | 8 只普通鸭 | 7 普通鸭 + 3 水鸭 |
| **核心挑战** | 学习基础驱赶 | 应对水域 + 水鸭 |
| **道具** | 无 | 面包屑（引诱水鸭） |
| **策略深度** | 走位 + 拍手 | 走位 + 拍手 + 涉水抉择 + 面包屑时机 + 桥头控制 |
| **地图尺寸** | 18×12m | 22×14m |
| **视觉主题** | 阳光草地 | 溪水 + 柳树 + 菜园 + 谷仓 |

### 9.2 三层策略递进

本关设计了三个策略层次，让不同水平的玩家都能找到乐趣：

| 层次 | 策略 | 适用场景 | 难度 |
|------|------|---------|------|
| **第一层：暴力过河** | 直接下水追鸭子 | 新手玩家的直觉反应 | 低效但可行 |
| **第二层：桥头控制** | 在桥头拍手，引导鸭子从桥面过河到目标区 | 理解地形后的自然策略 | 中等 |
| **第三层：面包屑配合** | 一人撒面包屑诱水鸭上岸，其余人拦截驱赶 | 满星必备的高级策略 | 需要配合 |

### 9.3 新增交互机制

| 机制 | 描述 | 设计意图 |
|------|------|---------|
| **涉水减速** | 玩家下水后移速 -50%、不能冲刺、拍手范围 -40% | 制造"追不上水中鸭子"的挫败→促使思考策略 |
| **水鸭回水本能** | 水鸭被赶上岸后会想回水 | 仅靠驱赶不够，需要面包屑辅助 |
| **面包屑引诱** | 吸引力 > 恐惧力，可诱导水鸭主动移动 | 首个非驱赶式的操控手段 |
| **菜园迷宫** | 低矮围栏挡玩家不挡鸭子 | 增加左岸驱赶的小型puzzle |
| **桥面瓶颈** | 唯一陆上过河点 | 天然的战略要地，鼓励玩家利用地形 |

### 9.4 多人合作的新分工模式

| 人数 | 推荐分工 |
|------|---------|
| **1 人** | 先用面包屑引水鸭上岸→赶普通鸭过桥→最后处理水鸭，节奏较慢 |
| **2 人** | A 在左岸赶普通鸭过桥，B 在右岸桥头接应+赶入围栏 |
| **3 人** | A 赶左岸，B 守桥头，C 负责面包屑+水鸭 |
| **4 人** | AB 左岸驱赶，C 桥头控制，D 面包屑+右岸入栏 |

## 十二、教学流程（隐式引导）

| 阶段 | 玩家体验 | 设计意图 |
|------|---------|---------|
| **开局** | 出生在左岸/右岸，看到溪流分割地图 | 认知"两岸"地形结构 |
| **首次接触溪流** | 试图走过去，发现移速变慢 | 理解溪流对玩家的限制 |
| **赶鸭子到河边** | 鸭子跑到水里，发现更难赶了 | 感受水域对鸭子的"保护"作用 |
| **发现石桥** | 绕路走桥，发现桥上是正常速度 | 学会利用石桥作为过河手段 |
| **遇到水鸭** | 水鸭移速比自己快、不怕拍手 | 产生"怎么办"的好奇心 |
| **发现面包屑** | 走到右岸木箱附近看到面包屑 | 学会新道具的存在 |
| **使用面包屑** | 撒下面包屑，水鸭主动靠过来 | 理解"引诱 vs 驱赶"的区别 |
| **桥头策略** | 在桥头拍手，鸭子被迫往右岸跑 | 掌握地形控制策略 |

### 14.2 水域检测方案

```lua
-- 简化方案：基于坐标判定（溪流路径用一组线段描述）
function IsInWater(position)
    -- 检测 position 到溪流中心线的垂直距离 < 溪流半宽
    for i = 1, #creekSegments - 1 do
        local dist = PointToSegmentDist(position, creekSegments[i], creekSegments[i+1])
        if dist < creekHalfWidth then
            return true
        end
    end
    return false
end
```
